# SQL_MOVIE_DATASET


## Overview

This repository contains a structured movie dataset in SQL format, designed for practicing SQL querying and data analysis techniques.

The dataset provides movie-related information including release year, movie title, actor, language, and director. It can be used to practice data retrieval, filtering, sorting, grouping, aggregation, and other fundamental SQL operations.

## Dataset Information

The dataset includes the following fields:

| Column     | Description                          |
| ---------- | ------------------------------------ |
| `rel_year` | Year in which the movie was released |
| `mov_name` | Name of the movie                    |
| `act_name` | Name of the actor                    |
| `lang`     | Language of the movie                |
| `dir_name` | Name of the director                 |

## Purpose

This dataset was used for hands-on practice with SQL and to develop practical skills in working with structured datasets.

It can be useful for practicing:

* Data retrieval using `SELECT`
* Filtering using `WHERE`
* Sorting using `ORDER BY`
* Grouping using `GROUP BY`
* Aggregate functions such as `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`
* Conditional analysis
* Basic data exploration using SQL
